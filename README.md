## Project Overview

The project focuses on Natural Language Processing (NLP), covering the core workflow used in text-based machine learning projects:

- Text preprocessing and cleaning
- Tokenization and normalization
- Stopword removal and stemming/lemmatization
- Feature extraction and model preparation
- Model training and evaluation
- Result interpretation and reporting

The main notebook is included at:

- [Local_NLP.ipynb](./Local_NLP.ipynb)

## Getting Started

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies.
4. Open the notebook in Jupyter or VS Code.

### Install dependencies

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt
```

### Open the notebook

```bash
jupyter notebook
```

Then open the notebook file named:

`Local_NLP.ipynb`
